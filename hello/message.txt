This text came from the boot archive. The kernel gave hello a handle to an
immutable file containing these bytes, along with a separate handle for its
space's console. The program can read the content and write to that console;
it does not need a filesystem path or access to the archive itself.

Hello asks for the file's size, reads at explicit byte offsets, and prints each
chunk using the console capability. A console write may accept only part of a
chunk, so the userspace helper keeps writing until that chunk is complete.

When the content reaches its end, hello closes both handles and exits. The
space keeps its console, and the shared boot archive keeps its original bytes.
